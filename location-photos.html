Foto Lokasi Billboard

Belum ada foto untuk lokasi ini.
Cara menambah foto
  1. Simpan file foto ke folder assets/img/locations/<lokasi>/
  2. Tambahkan datanya di data/location_photos.json
  3. Klik Refresh
Kunci <lokasi> mengikuti nilai filter lokasi, mis: pasir-kaliki, hang-tuah, raya-darmo.
